How it works

      

        
HookWhat Kompact does

        
PostToolUse · BashCompacts command output before Claude reads it. The raw output is kept locally; Claude can run kompact show <id>.

        
PreToolUse · ReadFirst read of a big file returns its outline with line ranges; reading again returns the whole file. Unchanged re-reads get a short note once.

        
SessionStartAdds the reply-style rules for your quality level.

        
StopTotals the turn's savings and shows them under Claude's reply, in the status line and in VS Code.
